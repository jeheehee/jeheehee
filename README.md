## Introduce
> 글로벌경제학의 시야, 개발의 논리, 기획의 감각으로 사람과 데이터를 잇습니다. <br>
> 비즈니스 이해와 기술 역량을 결합해 변화하는 시장 속에서 새로운 가능성을 만듭니다.

- 답이 정해져 있지 않은 문제를 좋아합니다.
- 한가지 문제도 여러가지 방법으로 푸는 게 좋습니다. 재미있거든요.
- 데이터 분석 결과가 끼칠 비즈니스 임팩트를 함께 고민합니다.
